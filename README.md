# 🌐 Ayush Girulkar Portfolio

This is my personal portfolio website built with **React + Vite**.  
It showcases my projects, skills, education, and experience.

### live: "https://ayushgirulkarportfolio.vercel.app/"

## 🚀 Features
- Fully responsive design
- Smooth animations using Framer Motion
- Project showcase with live links
- Contact form with EmailJS integration

## 🛠️ Tech Stack
- React
- Vite
- CSS (custom)
- Framer Motion

## 📦 Installation
1. Clone this repository  
   ```bash
    git clone https://github.com/ayushgirulkar/ayush_portfolio.git
   
2. Install dependencies :- 
    npm install
   
3. Run the project locally :-  
    npm run dev
